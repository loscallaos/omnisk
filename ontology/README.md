# Human Knowledge Ontology

## Purpose

This ontology defines the fundamental entities, concepts,
relationships and metadata required to represent human knowledge.

The ontology must be:

- domain independent
- extensible
- machine readable
- human understandable
- versioned
- source-aware
- multilingual
- capable of representing uncertainty
- capable of representing contradictions
- capable of representing historical change

## Core principle

Every piece of knowledge must be representable as structured
entities and relationships.

## Design principle

The ontology defines the structure of knowledge.

The knowledge itself is stored separately.
